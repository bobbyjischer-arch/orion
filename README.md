# 🛡️ O.R.I.O.N.

**Operational Response & Intelligence Observation Network** — система личной
безопасности: iOS-приложение + сервер (FastAPI) + Telegram-бот + веб-дашборд.

Приложение для людей в зоне риска: тихий SOS, «тихий сигнал» под принуждением,
ложное хранилище (decoy), таймер «Безопасный путь», передача координат
доверенным контактам, анализ обстановки и состояния.

Это открытая версия проекта: код целиком свой, никаких ключей и персональных
данных в репозитории нет — всё настраивается на своём сервере и своём телефоне.

## Структура

```
ios/        — iOS-приложение (Swift/SwiftUI) + виджет + Xcode-проект
server/     — core (FastAPI) + bot (aiogram) + дашборд + C++-ядро шифрования
.github/    — CI: неподписанный .ipa (macos-15 / Xcode 16.4) + тесты сервера
CLAUDE.md   — карта проекта: как что устроено и почему сделано именно так
```

## Возможности

- **iOS:** decoy-хранилище на неверный пароль, «тихий сигнал» (duress-код),
  «Безопасный путь» (dead-man таймер → авто-SOS), история перемещений
  с фильтром по дате/времени/месту, сбор состояния (шаги/вес/скринеры
  PHQ-2 и GAD-2/заметки), журнал записей с правкой и удалением за
  код-паролем, каскадное шифрование трафика, питомец-компаньон,
  единая дизайн-система (тёмная тема, cyan-акцент).
- **Сервер:** **AEGIS** — автономный «мозг» (работает без сети, ключей и
  нейросети; усиливается локальной Ollama или облаком OpenRouter, когда они
  доступны), накопительный счётчик подозрений с памятью привычных мест,
  персистентное хранилище устройств и трека, расшифровка каскадного трафика
  (C++-ядро + Python-эталон), auth `X-Orion-Key`, rate-limiting.
- **Бот:** опрос состояния при росте подозрения, экстренное оповещение
  доверенных контактов, owner-lock, персональный помощник.

## Код доступа

Предустановленного кода **нет**: исходники открыты, и любой зашитый в них код
был бы известен каждому, кто их читал. При первом запуске приложение просит
придумать код и повторить его; хеш кода хранится в Keychain. Забытый код
сбрасывается только переустановкой приложения.

Неверный код не сообщает об ошибке, а открывает ложное хранилище файлов —
из него можно войти в ORION, набрав свой код в строке поиска. Отдельный
«код тревоги» (задаётся в настройках) внешне открывает приложение как
обычно, но скрытно отправляет SOS с координатами.

## Запуск

Сервер и бот — см. [`server/DEPLOY.md`](server/DEPLOY.md):

```bash
cd server
cp .env.example .env          # заполнить секреты
pip install -r requirements.txt
uvicorn core.main:app --port 8080     # дашборд на http://localhost:8080
python bot.py                          # в отдельном терминале
```

Деплой на Render (бесплатный тариф, Blueprint `render.yaml`) — см.
[`server/DEPLOY.md`](server/DEPLOY.md), раздел «Render».

Тесты (те же четыре гоняет CI на каждый push):

```bash
cd server
python tests/test_store.py
python tests/test_aegis.py
python tests/test_aegis_memory.py
python tests/test_crypto.py
```

iOS собирается в CI (`.github/workflows/build.yml`) — артефакт `ORION-IPA`.
Локальная сборка требует macOS + Xcode 16.

## Безопасность

Секреты — только в `.env` (git-ignored) и в Keychain на устройстве.
Известные слабые места и то, что ещё не сделано, честно перечислены
в `CLAUDE.md` — читайте раздел «Security issues» перед тем, как полагаться
на приложение в реальной ситуации.
